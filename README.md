# campusflow_models

Atelier « Les modèles de CampusFlow en Dart pur » (90 min, binômes).

## Contenu
- `lib/models/` : `Task`, `Course`, `User` (attributs `final`, constructeur, `copyWith`, `fromJson`, `toJson`)
- `lib/repositories/` : dépôt simulé avec `Future.delayed`
- `test/` : 3 tests (`copyWith`, `fromJson`, erreur attendue)

## Utilisation
```bash
dart pub get
dart run bin/campusflow_models.dart
dart test
```
